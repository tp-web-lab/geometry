Introduction

Ce document, composé de plusieurs pages, illustre l’utilisation de la bibliothèque open source tp-components, conçue pour créer des documents techniques interactifs à des fins pédagogiques.

Il s’agit ici d’expérimenter les constructions géométriques à l’aide d’une règle et d’un compas.

Ces notes sont rédigées en tp-markdown pour HTML afin de pouvoir accéder plus facilement aux composants de la bibliothèque tp-components. Il est d’ailleurs possible de consulter le code source tp-markdown de la page courante en cliquant sur le bouton dans la barre d’outils en haut à gauche de ce document. On revient au rendu HTML en cliquant une nouvelle fois sur ce bouton.

Tous ces composants, et uniquement ceux-là, sont chargés automatiquement par le module tp-loader.js.

Ces composants peuvent utilisés eux-mêmes, de manière complètement transparente à l’utilisateur, d’autres composants de la bibliothèque tp-components.

Certains composants peuvent chargés dynamiquement des modules extérieurs, là encore de manière complètement transparente. C’est le cas de <tp-math> pour le rendu des formules mathématiques avec Mathjax, et de <tp-python-viewer-question> pour l’interprétation des programmes Python en ligne avec Pyodide.

Fichier index.html

Le fichier index.html est le point d’entrée de cette documentation : c’est le fichier HTML qu’il faut ouvrir dans le navigateur.

<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="description" content="Construire et démontrer en géométrie avec une règle et un compas virtuels.">
  <title>Constructions géométriques</title>
  <link rel="icon" href="/docs/logo-tp.svg" type="image/svg+xml">
  <script  type="module" src="./@tp/tp-components/tp-loader.js"></script>
</head>
<body>
  <tp-markdown-multi-pages menu repository="/docs" label="Constructions géométriques"></tp-markdown-multi-pages>
</body>
</html>

En-tête

L’en-tête (section <head>...</head>) du fichier précise que la langue utilisée est le français (attribut lang="fr" de la balise principale <html>...</html>), définit le texte qui sera affiché dans l’onglet de la page Web (balise <title>) et surtout, importe le fichier tp-loader.js qui a la responsabilité de charger automatiquement et dynamiquement, au fil des pages, les composants de la bibliothèque tp-components utilisés dans les différents fichiers visités.

<script type="module" src="./@tp/tp-components/tp-loader.js"></script>

Dans un script, l’attribut type="module" indique au navigateur que le script est un module JavaScript, qui peut notamment importer d’autres modules avec import et exporter des fonctions ou des valeurs avec export. Cela change aussi son comportement :

  • Exécution différée : le navigateur télécharge le module et ses dépendances, puis l’exécute après l’analyse du document HTML.
  • Portée propre : ses variables et fonctions ne sont pas globales et ne sont pas accessibles aux autres éventuels scripts exécutés dans cette même page Web.
  • Mode strict automatique : certaines erreurs JavaScript tolérées dans les scripts classiques sont interdites.
  • Chargement unique : un même module, identifié par son URL, n’est exécuté qu’une fois dans la page, même si plusieurs modules l’importent.

Corps

Le corps (section <body>...</body>) du fichier est juste constitué du composant <tp-mardown-multi-pages> qui se charge de la mise en page dans le navigateur : une barre d’outils en haut de la page, une table des matières générale dans le panneau de gauche et le contenu principal dans le panneau de droite.

<body>
  <tp-mardown-multi-pages menu langs="fr" repository="/geometry/docs" label="C’est quoi, une dérivée ?"></tp-markup-multi-pages>
</body>

Ce composant recherche les fichiers à charger dans le répertoire /geometry/docs (attribut repository="/geometry/docs"), affiche la table des matières générale (attribut booléen menu) et précise que les langues accessibles sont l’anglais et le français (attribut langs="en,fr"). L’attribut label sert à afficher un titre dans la barre d’outils du haut de la page.
